# Tasks

_Discrete action items. Separate from project workstreams in PLAN.md — these are things that need a specific person to do a specific thing._
_**On Deck** is the short morning slate (surfaced first at every session start). **Active** below is the full backlog._

## On Deck — Next Session

_The few things to pick up next. Edit this at the end of a session; the session-start hook surfaces this block first so it's the first thing you see when you sit down. Keep it short — promote anything larger into Active below or a workstream doc._

_A session works **one** of these. Where an entry points at a workstream doc, that pointer is an **address, not an instruction to read it now** — open a workstream body only once we've committed to that thread, and only that thread's. Reading the candidates up front pays for every thread to work one. See `.claude/rules/session-start.md` § Initialization stops at the index._

## Format

```
### [Task title] (references)
**Priority:** P0 (urgent/blocking) | P1 (important, do soon) | P2 (should do) | P3 (when time permits)
**Owner:** Who's doing this
**With:** Other participants/stakeholders (if any)
**Deadline:** Hard date, or "none" — explain why if there is one
**Deliverable:** What "done" looks like
**Context:** Why this matters, what it connects to
**Blocked by:** What's preventing progress (if anything)
```
